Open source control (3rd icon from the top in the left sidebar), download git when it asks you  
Run in VS Code shell (ctrl+\`):  
```
git config --global user.name "Your Name"
git config --global user.email "Your Github Email"
```
To upload any changes, go to source control, enter a commit message (just above commit button) and press commit, then sync  
First commit will ask to log in with github  
If making big changes, make new branch (3 dots that appear when you hover near commit button and field), then publish it
